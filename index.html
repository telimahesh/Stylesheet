Important

StyleSheet Affiliate Pro needs PHP + MySQL hosting

You are currently viewing this repository on GitHub Pages (*.github.io), which only serves static files and cannot run .php code or MySQL.

To run the full app, deploy this project to a PHP server (XAMPP/cPanel/EC2/Lightsail/ECS).

Quick run steps

  • Copy stylesheet_pro/ to your PHP host document root.
  • Create MySQL access for 127.0.0.1 / root / root (or update config).
  • Open /stylesheet_pro/install.php once to set up schema and sample data.
  • Browse /stylesheet_pro/index.php and /stylesheet_pro/admin/login.php.

Repository docs are available in docs/DEPLOYMENT.md.
